# DSA 🚀

Welcome to my **Data Structures and Algorithms (DSA)** repository! 

## 📖 About
This repository contains a collection of my solutions to various DSA questions, primarily from LeetCode. It serves as a personal archive of my coding journey, problem-solving progress, and algorithmic practice. 

## 💻 Languages Used
The solutions in this repository are predominantly written in:
* **Java** 
* **C++**

## 📂 Repository Structure
The repository is organized into folders by problem number and name (e.g., `14-longest-common-prefix`, `486-predict-the-winner`). Each folder contains the solution code and sometimes specific notes or problem descriptions.

## ⚙️ Workflow
I use **LeetSync** to automatically push my accepted LeetCode solutions directly to this repository, keeping my progress accurately tracked and up to date!
